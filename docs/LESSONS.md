# دروس مستفادة (ذاكرة الوكيل)

اقرأ هذا الملف في بداية كل جلسة. عند أي خطأ أو فشل أو تصحيح من المستخدم: أضف درسًا جديدًا هنا **في نفس الجلسة**.
الصيغة: التاريخ — ما حدث — السبب — القاعدة الجديدة — (اختبار يمنع تكراره إن أمكن).

## 2026-11-23 — الجلسة 1
1. **تنزيل محركات Prisma محجوب في البيئة** → فشل `prisma migrate`. القاعدة: Drizzle هو ORM المشروع؛ لا تعد إلى Prisma.
2. **`getByRole("alert")` في Playwright يلتقط معلن التنقل الخفي في Next.js** (`#__next-route-announcer__`). القاعدة: استخدم `p[role=alert]` أو `getByText` لرسائل الخطأ.
3. **لقطة `fullPage` على أجهزة اللمس (آيباد) تعيد تخطيط الصفحة مؤقتًا** فيفشل النقر بعدها (timeout). القاعدة: بعد لقطة fullPage انتقل بالرابط (`goto(href)`) أو انتظر الاستقرار قبل النقر.
4. **`.gitignore` الافتراضي في Next.js يستبعد `.env*`** فاستُبعد `.env.example` أيضًا. القاعدة: استثناءات `!.env.example` و`!.env.test.example` موجودة؛ تحقق بـ `git ls-files` قبل كل دفع.
5. **أُضيف `test-results/` للمستودع بالخطأ** لأن `git add -A` نُفّذ قبل تحديث `.gitignore`. القاعدة: حدّث `.gitignore` أولًا ثم أضف، وراجع `git status` قبل الالتزام.
6. **الدفع إلى GitHub رُفض (403)** حتى ثُبّت تطبيق Claude على المستودع. القاعدة: إن تكرر الرفض، اطلب من المستخدم تثبيت التطبيق بدل إعادة المحاولة.
7. **عرض الأرقام بالأرقام الهندية جعل الصفر «٠» يبدو كنقطة** في بطاقات لوحة التحكم. القاعدة: الأعداد في البطاقات بأرقام `en-US`.
8. **أسماء العمليات في سجل التدقيق ظهرت بالإنجليزية** (login · user). القاعدة: كل نص يراه المستخدم يُترجم عبر خريطة عربية.
9. **التُزم ملف `school-directory.zip` داخل المستودع بالخطأ.** القاعدة: `*.zip` في `.gitignore`، وملفات التسليم تُنشأ خارج مجلد المشروع (`../`).

## 2026-11-23 — الجلسة 2 (المرحلة 4)
10. **React 19 يمسح حقول النموذج تلقائيًا بعد كل إرسال عبر `<form action>`** حتى عند فشل التحقق، فضاعت مدخلات المستخدمة (فشل 9 اختبارات Playwright). السبب: سلوك إعادة الضبط الافتراضي في React 19. القاعدة: `ActionForm` يرسل يدويًا (`onSubmit` + `startTransition(() => formAction(fd))`)، وتُعاد تهيئة الحقول بعد النجاح بمفتاح `key={version}`. اختبار الانحدار: `e2e/phase4.spec.ts` (إدخال تاريخ قيد فارغ ثم تصحيحه دون إعادة كتابة الاسم).
11. **اختبار قرأ «آخر سجل تدقيق» بعد عملية دخول لاحقة** فوجد `login` بدل `password_change`. القاعدة: تحقّق من سجل التدقيق مباشرة بعد العملية المقصودة وقبل أي عملية تكتب تدقيقًا آخر.
12. **`Pick<DB, "select">` لا يشمل `selectDistinct`** فظهر خطأ أنواع. القاعدة: اجعل نوع المعامل يطابق الدالة المستخدمة فعلًا (`Pick<DB, "selectDistinct">`) وشغّل `tsc` بعد كل خدمة جديدة.
