# سجل التقدم

## الجلسة 1 — 2026-11-23

### قرارات وافتراضات (لم ترد إجابات بعد)
- **حفظ الكود:** لم يُحدَّد مستودع GitHub بعد → سُلّم المشروع ملف zip. المستخدم يرغب بنقله إلى Claude Code عبر مستودع **خاص**.
- **أوقات الحصص والسنة الدراسية:** غير مُقدَّمة → تواريخ السنة 1448هـ في البيانات الوهمية **عناصر نائبة** (موسومة «تجريبي»)، وأوقات حصص تجريبية للابتدائية فقط لإظهار الحالتين. الروضة والمتوسطة تُظهران «أوقات الحصص غير مكتملة».
- **المرفقات (الجداول والكشوف):** لم تُرفع في هذه الجلسة → المرحلة 1 (تحليلها) مؤجلة. انظر OPEN_ISSUES.
- **ORM:** Drizzle بدل Prisma (تنزيل محركات Prisma محجوب في بيئة البناء). المواصفات تسمح بـ«بديل مناسب».
- **هوية القيادة:** الأسماء الحقيقية لا تُخزّن في المستودع؛ تُقرأ من `data-private/school-identity.json` (مستبعد من Git) وإلا تظهر عناصر نائبة.

### ما أُنجز فعليًا
- مخطط PostgreSQL من 39 جدولًا + ترحيل `drizzle/0000_init.sql`، بقيود قاعدة بيانات تمنع: تعارض المعلمة/الفصل/القاعة في الجدول، تكرار الانتظار، البديلة لنفسها، الغياب المكرر، سنتين نشطتين، قيدين للطالبة في سنة، تكرار تاريخ المباشرة لنفس النوع، تكليف مراقبة بلا يوم أو تاريخ.
- RBAC: 33 صلاحية، 4 أدوار نظامية (المديرة، وكيلة الشؤون التعليمية، وكيلة شؤون الطالبات، مسؤولة الدليل)، تقييد اختياري بالمرحلة لكل إسناد دور.
- مصادقة: bcrypt (12)، جلسات في قاعدة البيانات (تجزئة SHA-256 للرمز، كوكي httpOnly)، قفل بعد 5 محاولات لمدة 15 دقيقة، إبطال الجلسات عند تعطيل الحساب، سياسة قوة كلمة المرور، `mustChangePassword` (شاشة التغيير لم تُبنَ بعد).
- سجل تدقيق يحجب كلمات المرور والرموز تلقائيًا.
- منطق المجال: تطبيع البحث العربي، توقيت الرياض، التحويل الهجري (أم القرى) وقراءة تواريخ المستندات دون تخمين، الحصة الحالية، التأخر، التداخل، القفل التفاؤلي.
- خدمات: البحث الشامل المقيّد بالصلاحية، لوحة التحكم من قاعدة البيانات، «الموقع المتوقع للطالبة» (الجدول + الانتظار + الاستثناءات).
- واجهة عربية RTL بخط IBM Plex Sans Arabic محليًا، متجاوبة (كمبيوتر/آيباد/جوال)، ترويسات أمان (CSP، منع التأطير…).
