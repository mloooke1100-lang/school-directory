# حماية البيانات

- **لا يوجد أي حقل لرقم السجل المدني** في قاعدة البيانات (يتحقق اختبار آلي من عدم وجود أعمدة بأسماء national/civil/iqama/id_number).
- لا تُستخدم الأسماء مفاتيح؛ كل شخص بمعرّف UUID.
- بيانات التطوير والاختبار وهمية بالكامل وموسومة «تجريبية/تجريبي».
- `data-private/` و`.env` و`backups/` مستبعدة من Git.
- كلمات المرور bcrypt، ورموز الجلسات تُخزّن كتجزئة SHA-256 فقط، والكوكي httpOnly + SameSite=Lax + Secure في الإنتاج.
- سجل التدقيق يحجب `password*`, `token*`, `mfaSecret` تلقائيًا.
- كل وصول للبيانات يمر بفحص الصلاحية على الخادم، مع تقييد بالمرحلة.
- ترويسات أمان: CSP صارمة، X-Frame-Options: DENY، nosniff، Referrer-Policy، robots noindex.
- الصور التي تحتوي بيانات شخصية لا تُرسل لأي خدمة OCR خارجية.
- لا تُنشر أي بيانات حقيقية قبل اعتماد الاستضافة والموافقات الرسمية.
